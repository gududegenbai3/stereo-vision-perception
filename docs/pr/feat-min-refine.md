# PR：置信度驱动精算的最小可运行实现（harness 版）

> 分支：`feat/min-refine`　｜　涉及：`src/`、`tests/`、`configs/`、`docs/`、`AGENTS.md`
> 对应计划：`plans/phase-1/plan.md` 第四节（三步流程）与第五节（三条曲线 + 速度）

## 一、变更内容

1. **`src/stereo_min/`**：粗算 → 自查 → 预算化分配 → 精算 → 评测的完整链路，仅依赖 OpenCV SGBM，无训练、无 GPU、无外部数据。
2. **`tests/`**：13 个单元测试（LRC 语义、预算数量精确性、指标口径）。
3. **`selftest.py`**：零数据自检 17 项，含结构不变量"预算 100% 时自适应与随机必须选中同一批像素"。
4. **`configs/`**：`synthetic.json`（合成图）与 `default.json`（真实数据起步参数），参数外置、无本机路径。
5. **`AGENTS.md`**：稳定的 AI 协作约束（目录归属、验收门、红线、PR 格式）。
6. **`docs/pr/` + `docs/research/notes/`**：PR 四段模板落地、论文笔记按既有模板与命名给出样例。

## 二、验证命令与输出

```bash
pip install -r requirements.txt
python selftest.py            # 17/17 PASS
python -m pytest tests -q     # 13 passed, 0 failed
python run_experiment.py --out artifacts/2026xxxx_min_refine
```

合成图（240×480，三段平面 6.0/9.5/4.0 px）实测：

| 变体 | 预算 | 覆盖率 | EPE | 总耗时 | ROI | ms/千有效像素 |
|---|---|---|---|---|---|---|
| A 全粗算 | 0 | 0.717 | 0.976 | 6.0 ms | 0 | 0.07 |
| B 全精算 | 1.00 | 0.723 | 0.966 | 41.7 ms | 1 | 0.50 |
| C 自适应 | 0.10 | 0.743 | **0.900** | 21.7 ms | 20 | 0.25 |
| R 随机 | 0.10 | 0.731 | 0.934 | 26.7 ms | 32 | 0.32 |
| C 自适应 | 0.20 | 0.773 | **0.812** | 21.7 ms | 20 | 0.24 |
| R 随机 | 0.20 | 0.746 | 0.891 | 26.7 ms | 32 | 0.31 |
| C = R | 1.00 | 0.860 | 0.558 | 26.8 ms | 32 | 0.27 |

结论：①同预算下自适应优于随机（10% 时 EPE 低 3.6%，20% 时低 8.9%）；②自适应所需 ROI 更少（20 vs 32），因为被挑中的像素成簇；③曲线三显示 C@20% 用 3.4× A 的开销换到 17% 的 EPE 下降，而 B 用 7× 开销只换到 1%——C 落在 A–B 的更好一侧；④100% 预算时 C 与 R 必然相同（自检守住）。

## 三、已知未知项

1. **能耗未测**：曲线三目前是"每千有效像素的毫秒数"，不是焦耳；等硬件（INA219/功率计）到位后同口径替换，字段名不变。
2. **端到端时延缺失**：只覆盖算法部分（粗算 + 自查 + 精算），不含采集、传输、显示。
3. **自查只有一种信号**（左右一致性）：计划 §4.2 要求前三种（LRC / 代价曲率 / 时序一致性）横向对比，当前完成第一种。
4. **无真实数据**：所有数字来自合成图，纹理是随机构造的，**不能据此判断算法优劣**。
5. **未做升分辨率式精算**：精算目前是"局部搜索范围 + 更小窗口"，不含"提高分辨率重算"。
6. **PNG 依赖 matplotlib**：未安装时只写 CSV（不报错），因此 CI 里若没有 matplotlib，"曲线图"产物会缺失——`rows.csv` 与 `risk_coverage.csv` 仍然完整。

## 四、风险

1. **合成图结论偏乐观**：缓解是所有报告数字都标注数据来源，真实数据结论以 Middlebury/ETH3D 与自采为准。
2. **ROI 精算在视差范围很大时会退化成整图重算**（SGBM 要求窗口宽度 > minDisparity + numDisparities）：缓解是用局部搜索范围收窄 numDisparities，并在 `rows.csv` 记录 `rois` / `processed_px` 便于发现退化。
3. **`penalty=3 px` 会影响结论方向**：缺测惩罚越小，"拒绝输出"越划算；报告须写明该值，并用另一档口径复算一次。
4. **参数档依赖场景**：`block_size` / `uniqueness_ratio` 无通用最优值，`configs/default.json` 只是起步值，需按自采数据重扫。
5. **单帧无时域**：动态场景下不做时序一致性，避免误判，但也失去一个免费的置信度来源。
