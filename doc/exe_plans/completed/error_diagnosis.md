# V0 SGBM 结果误差诊断

日期：2026-11-15。状态：已完成诊断并验证；未实施精度修复。按用户要求诊断仓库现有基础版，不修改匹配器，不调优已冻结的置信度实验。

## 固定范围与口径
- 基线为 main 54ce534 的匹配实现及 config/offline.json 参数，依赖使用已有 SVP_env。
- 复跑全部15个 Middlebury trainingQ 场景；推断只调用现有 compute_disparity，真值只在其后参与诊断。
- 主评价域沿用原流程：有限非遮挡真值与有效预测的交集；额外报告全部参考像素的预测缺失，区分搜索 ROI 外与 ROI 内。
- Bad-2 定义为绝对视差误差严格大于2像素。误差分档、区域内错误率、占全部错误比例、绝对误差和贡献分别统计。
- 互斥区域按优先级划分：真值超出配置搜索范围、真值视差突变带、非突变带低纹理、其余区域。区域定义参数唯一来源为 config/error_diagnosis.json。
- 突变种子只使用相邻有限真值的差，不将 NaN/Inf 产生的边缘当作深度跳变；边界带为方形邻域膨胀。纹理为左图灰度局部标准差。
- 遮挡真值区单独统计，不混入主流程的非遮挡错误构成。区域标签只描述共现，不冒充逐像素因果分类。
- 复核边界阈值/带宽敏感性；明确池化像素汇总与场景等权汇总的区别。诊断不会改变已有实验划分或成为新的算法调参结果。

## 交付与验收
- 独立诊断入口、机器可读 JSON/CSV、逐场景数组与真实图像对照；面向用户的解释在会话提供。
- 核对区域互斥完备、分档合计、参考域与原 evaluate_disparity 一致；检查错误条件和有效掩码语义。
- 输出错误来源区域排序、场景贡献排序和典型原图/真值/预测/误差裁剪。对成因说明区分代码事实与待消融验证的推断。
- 未授权提交或上传；保护当前工作区其他任务修改。

## 实测结果与证据
- 15/15 场景成功，0 失败；Python 3.11.18 / OpenCV 4.13.0。主评价参考像素4,041,771，其中可评价预测3,228,415，覆盖79.8762%；Bad-2 共444,633，占可评价预测13.7725%。池化MAE 2.744681 px，RMSE 10.996986 px；场景等权MAE 2.953508 px。此处15场景像素池化不同于此前11场景等权置信度实验，不直接比较两次均值。

| 互斥区域 | Bad-2点数 | 占全部Bad-2 | 区域内Bad-2率 | 占绝对误差和 |
|---|---:|---:|---:|---:|
| 非边界低纹理 | 243421 | 54.7465% | 16.7525% | 52.6464% |
| 真值视差突变带 | 141516 | 31.8276% | 24.9065% | 27.0981% |
| 其余区域 | 43229 | 9.7224% | 3.6325% | 14.0066% |
| 真值超出搜索范围 | 16467 | 3.7035% | 96.1240% | 6.2489% |

- 大于10px的194,777个点仅占可评价预测6.033%，贡献76.2560%的绝对误差和。应关注大错配，而不是只优化小数位。
- 非遮挡参考中813,356点无有效预测：645,941点在搜索ROI外，167,415点在ROI内。它们不算0误差，也未混入上述错误率。
- 有限真值但非双侧可见区单独统计：544,239参考点，192,988点有预测，覆盖35.4602%；其中152,197点为Bad-2，条件错误率78.8635%。这不是主评价非遮挡区域的附加可相加错误比例。
- Bad-2场景贡献前三为PianoL 15.3286%、Shelves 12.9113%、Vintage 11.7625%（占所有Bad-2，不是各场景内部错误率）。
- Piano/PianoL：逐像素核对左图、GT与非遮挡掩码一致，右图不同；共同有效196,916像素上Bad-2从15.1491%升至33.7824%，MAE从1.639946升至13.832913px。Motorcycle/MotorcycleE共同有效241,350点上Bad-2从3.9664%升至12.0443%。官方E/L分别表示改变曝光/光照；这些实际对照说明辐射变化需要独立关注。
- 9组边界阈值/带宽诊断下（排除搜索范围外优先类），边界错误份额15.77%至42.92%；非边界低纹理在9组中均为最大份额。不能将31.83%称为精确的物体边界因果比例；梯度带不是语义轮廓标注，低纹理也可能同时受光照、反射或其他因素影响。
- 实图按配置事后选择：Shelves平滑墙面、Adirondack扶手C点、Jadeplant超范围前景、MotorcycleE其余区域。裁剪内高错误密度不代表整体平均；完整统计来自全部15场景。

## 当前匹配器机制核对
- src/disparity.py使用灰度输入、5×5块、P1=200、P2=800和基本SGBM模式。OpenCV 4.13采用BT代价及5方向路径聚合；固定支持域可能跨越前后景，固定平滑项可能影响真实突变，低纹理的候选区分度可能不足。这些是结构性解释，尚未通过消融分离各因素贡献。
- 实际getter：uniquenessRatio=0，不要求正的唯一性裕量；speckleWindowSize=0，不做speckle连通域过滤，但库内部仍有3×3中值滤波。
- 不能说完全没有左右一致性检查：disp12MaxDiff存储为0，但此版本源码内部回退为有效阈值1；该右侧缓冲检查也不等于独立完整右匹配。
- 官方证据：[OpenCV 4.13类说明](https://docs.opencv.org/4.13.0/d2/d85/classcv_1_1StereoSGBM.html)、[源码参数与递推](https://github.com/opencv/opencv/blob/4.13.0/modules/calib3d/src/stereosgbm.cpp#L469)、[中值与斑点处理](https://github.com/opencv/opencv/blob/4.13.0/modules/calib3d/src/stereosgbm.cpp#L2070)、[Middlebury E/L说明](https://vision.middlebury.edu/stereo/eval3/MiddEval3-newFeatures.html)。
