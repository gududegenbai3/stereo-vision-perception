# 传统 SGM 机制补充与受控对照

日期：2026-11-15；状态：机制已实现并验证，对比已完成；未设为默认算法。用户要求优先补充原论文已有机制并观察实图变化。

## 范围与固定协议
- 现有 OpenCV SGBM 已完整调用，不称为未完成的库实现；原始 SGM 与 SGBM 不等价。基线函数和 config/offline.json 保持不变。
- Python 3.11、已有 OpenCV/NumPy，无新增依赖。原论文可选的单像素 BT、8路径递推、固定/自适应 P2、亚像素、3×3中值及独立左右检查由独立 NumPy 实验后端实现。
- 固定/自适应对照共享所有其他步骤，右匹配通过同时水平翻转并交换图像后计算，返回同为正方向的右视差。额外平均匹配惩罚组只根据输入图像确定均匀P2，区分空间变化与整体减弱平滑。
- 自适应P2为max(P1,P2_base/max(1,abs(I(p)-I(p-r))))；零分母处理和上限是工程约定。像素BT代价尺度使用配置预设P1/P2，不搬用5×5基线的200/800。
- OpenCV另设8路径HH、唯一性裕量与斑点过滤组，说明它主要改变路径和拒绝策略，不冒充开启了自适应P2。
- 不实现MI代价、多基线融合、论文特定平面修复或遮挡补洞，不宣称全文复现。新增实验不用GT决定预测或参数；已看过的15诊断场景只用于描述性对比，不作为独立泛化测试。
- 参数唯一来源config/sgm_comparison.json。区域定义复用诊断配置。分别记录原始WTA及同一后处理结果、共同有效域误差、覆盖率、缺失计错、时间与失败。
- 验收覆盖合成已知位移、左右符号、路径递推、单变量开关、有效掩码和实际场景回归；实图同色标、不以删点造成的低误差冒充修复。

## 论文与实现边界
- 论文§2.1允许BT或MI像素代价；本轮实现BT，不是HMI主实验复现。§2.2给出至少8路径与自适应P2；零分母和有限上限由工程约定补充。
- 论文没有披露可直接复用的BT专用P1/P2组合。8/32是本轮预先固定的工程设置，不是论文的原始实验参数。没有在结果出现后改这组参数。
- 原文§2.3先3×3中值再左右检查，容许差≤1px；本轮独立重算右图并使用最近像素采样。遮挡/误配分类补洞、强度一致性平面修复和多基线融合均未实现，不称“原论文所有步骤已做完”。
- 主源：[Hirschmueller 2008](https://www.cvlibs.net/projects/autonomous_vision_survey/literature/Hirschmueller2008PAMI.pdf)，尤其§2.1—2.3；OpenCV相关语义沿用已归档诊断记录。

## 实测结果（15/15场景，0失败）
以下按像素池化，参考域与原诊断相同。Bad-2严格大于2px；“缺失计错”将无有效输出也记为未给出正确答案。

| 方法 | MAE(px) | 有效点Bad-2 | 覆盖率 | Bad-2＋缺失 |
|---|---:|---:|---:|---:|
| 原OpenCV | 2.744681 | 13.7725% | 79.8762% | 31.1247% |
| OpenCV HH＋唯一性/斑点筛选 | 1.523692 | 8.5514% | 74.5350% | 31.8387% |
| OpenCV按标定提示扩范围 | 2.637451 | 13.3881% | 79.2191% | 31.3869% |
| 像素SGM固定P2，检查后 | 2.958457 | 18.7918% | 49.9751% | 59.4161% |
| 像素SGM自适应P2，检查后 | 3.567654 | 21.8299% | 43.7313% | 65.8153% |
| 像素SGM输入均值匹配固定P2，检查后 | 3.298405 | 20.3244% | 48.1961% | 61.5995% |

- OpenCV补充组在与原基线共同有效的点上，MAE从约1.627降至1.455px，存在真实数值改善；同时损失254,225个原有效点、新增38,345个点，整体缺失计错并未改善，不能只报MAE降低44.5%。
- 范围组只在Jadeplant（提示160）和Vintage（提示190，取192）改变搜索范围。Jadeplant MAE 6.704803→4.8838px，有效点Bad-2 22.5833%→15.98%，缺失计错40.23%→37.04%；但Vintage及总覆盖率存在代价，不能自动将该配置全局替换。
- 只比较同后端原始WTA输出时，固定/自适应覆盖率均85.3996%，Bad-2从39.0193%升至48.2622%，MAE从10.671106升至13.400594px；平均匹配惩罚固定组Bad-2为42.6208%。自适应的退化并非由后处理删点造成。
- 原始像素SGM固定/自适应逐点对比：1,310,667点误差下降，2,025,133点上升，115,857点相同。预设BT代价/参数在当前真实数据上较差；递推、符号与合成位移检查通过，仍不能排除尚未覆盖的实现或参数适配问题。
- Adirondack扶手C点：GT52.3228、原预测80；OpenCV补充组及新SGM的检查后输出均为无效。该点是拒绝错误，不是成功修复。
- 新NumPy后端单场景双向计算耗时数秒，远慢于原OpenCV，不满足实时目标。完整墙钟时间见summary.json，不当作相机帧率。
