# 执行计划与进展

- `active/`：尚未完成的计划，包括进行中、待启动及局部受阻的任务。
- `completed/`：通过计划完成条件、保留验收证据后归档的计划。
- 当前 V0 计划：[V0_stereo_pipeline.md](active/V0_stereo_pipeline.md)。

每份计划维护任务状态、依赖、验收依据、当前阻碍和下一步。项目进展以当前活动计划的状态摘要为入口，不另维护重复的 `progress.md`。

任务状态使用“待开始、进行中、已验证、受阻”。有实现但未运行验证的任务仍是“进行中”；硬件没有记录或实测证据时标记“待验证”，不能视为已通过。某项受阻只影响依赖它的任务，其余路线继续推进。

每次相关工作开始时核对仓库文件、配置、运行记录及用户提供的实测结果；工作结束时更新活动计划的任务状态和进展记录。记录日期、任务 ID、具体变化、验证命令或证据位置、结果、限制与下一步。机器可读运行参数仍在 `config/`，计划只引用配置及证据。

归档时先检查该计划的完成条件，填写结论、复现入口及剩余限制，再将原文件移入 `completed/` 并更新本索引和项目入口链接；检查移动后相对链接是否有效。完成计划不等于硬件精度已达标，二者按各自证据判断。

`completed/.gitkeep` 用于保留初始空目录，不代表已有完成计划。
